Quelques notions
de code et le TDD

Notion 1 sur 6

Variable

Une valeur qui porte un nom.

jeu.dart
final jet = 11;
final bonus = 3;
final total = jet + bonus;   // 14
Notion 2 sur 6

Fonction

Une recette réutilisable.

jeu.dart
int ajouterBonus(int jet, int bonus) {
  return jet + bonus;
}

ajouterBonus(11, 3);   // 14
Notion 3 sur 6

Condition

Un choix : si… sinon…

jeu.dart
if (total >= dd) {
  print('Réussite');
} else {
  print('Échec');
}
Notion 4 sur 6

Boucle

Répéter pour chaque élément.

jeu.dart
for (final quete in ['Forêt', 'Donjon', 'Marais']) {
  print('Quête : $quete');
}
Notion 5 sur 6

Fichier

Lire et écrire sur le disque.

jeu.dart
import 'dart:io';

File('journal.txt').writeAsStringSync('Quête terminée');

Lire un code, c'est reconnaître ces six briques
jeu.dart
const dd = 12;                      // variable

bool estReussite(int total, int dd) { // fonction
  return total >= dd;
}

void main() {
  for (final jet in [8, 12, 17]) { // boucle
    if (estReussite(jet, dd)) {      // condition
      print('$jet réussite');
    }
  }
}
