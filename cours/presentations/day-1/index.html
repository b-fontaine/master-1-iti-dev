Les notions de code · Python → Dart
jeu.py · ce que vous connaissez
jet = 11                      # variable

def ajouter(jet, bonus):  # fonction
    return jet + bonus

if total >= dd:             # condition
    print("Réussite")
else:
    print("Échec")

for quete in quetes:      # boucle
    print(quete)
jeu.dart · le même programme
final jet = 11;                // variable

int ajouter(int jet, int bonus) { // fonction
  return jet + bonus;
}

if (total >= dd) {            // condition
  print('Réussite');
} else {
  print('Échec');
}

for (final quete in quetes) { // boucle
  print(quete);
}
des types : int, String, booldes { } et des ;final = ne change plus'$quete' = f"{quete}"

08

RGPD
et AI Act

Deux textes européens
RGPD · depuis 2018

Protéger les données personnelles

On ne traite que le nécessaire, pour un but précis, et la personne garde ses droits.

AI Act · 2024

Encadrer l'IA selon le risque

Plus un usage touche aux personnes, plus les obligations sont lourdes.

À respecter dans vos projets
1

Aucune donnée personnelle ou confidentielle dans un prompt ni un dépôt public

2

Des données fictives ou générées

3

Aucune clé ni mot de passe : .env hors dépôt

4

Ne collecter que le nécessaire, avec une date de suppression

5

Dire quand on parle à une IA ou quand un contenu est généré

6

Un humain relit et décide : validation du RSSI avant tout usage réel
