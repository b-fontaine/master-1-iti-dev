Thème A · les défis

Les dés en dur

Le dé vient de l'extérieur

Un test d'architecture échoue si le domaine importe du hasard. Le dé est injecté, rejouable.

conformité

Sensibilité faible. Un pseudonyme de joueur reste une donnée personnelle : information et suppression.

Thème B · les défis
le piège de l'agent

Les unités mélangées

Secondes divisées par des minutes : la performance est 60 fois trop haute, et le plafond à 100 % cache l'erreur.

le garde-fou

Un seul endroit pour convertir

Suffixes d'unités obligatoires. Un test échoue si 60 ou 3600 apparaissent ailleurs.

conformité

Mesurer une machine, pas une personne

Sensibilité moyenne. Un TRS par quart peut évaluer indirectement un opérateur.

Thème C · les défis

Les données réelles collées
