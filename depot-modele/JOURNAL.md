# Journal de l'équipe

Ce fichier garde la mémoire du projet : où l'on en est, ce que l'on a décidé et ce que l'on a appris. Il est écrit pour quelqu'un qui aurait tout oublié : vous dans quelques semaines, ou un coéquipier absent. Le gardien du harnais le tient à jour. Aucun nom complet, aucune adresse, aucune donnée réelle : le dépôt est public.

## État courant (à compléter : date et séance)
- Où on en est : équipe n° X, thème à compléter ; état du dépôt et des postes ; PR fusionnées.
- Prochaine étape : à compléter.
- Commandes clés : flutter pub get · dart run build_runner build --delete-conflicting-outputs · flutter test · flutter run -d chrome.
- Décisions : à compléter.
- Reste à faire : à compléter.

## Décisions et apprentissages

Une entrée par décision ou par apprentissage : date, ce qui a été décidé ou appris, pourquoi.
