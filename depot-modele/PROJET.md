# PROJET.md : en attente du thème de l'équipe

Ce fichier est un fichier d'attente. À la création de votre dépôt, la version de `PROJET.md` pour le thème de votre équipe (`themes/PROJET-A.md`, `themes/PROJET-B.md` ou `themes/PROJET-C.md`) est copiée ici, à la place de ce texte.

Si ce texte est encore là, la copie n'a pas été faite. Faites-la à la main :

1. Repérez le thème de votre équipe : A, B ou C.
2. Copiez le contenu de `themes/PROJET-<A|B|C>.md` à la place de tout ce fichier (remplacez `<A|B|C>` par la lettre de votre thème).
3. Remplacez « équipe n° X » par le numéro de votre équipe.
4. Passez par une branche et une pull request, comme pour toute modification.

Une fois `PROJET.md` à jour, l'équipe le relit, retient 3 à 5 user stories, ajuste le texte et décide.
